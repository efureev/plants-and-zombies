Собственные персонажи мода. Процесс и чек-лист — `docs/SPEC.md` §9, техническая часть — `docs/WORKSHOP.md`.

Код — в пакете `dev.efureev.sproutsquad.content.*`, исходники Blockbench и эскизы — в `art/<id>/`.

## Реестр

|---|---|---|---|
| `potling` | Горшочек / Potling | растение | в коде |

Статусы: `идея` → `модель` → `в коде` → `готов`.

---

### Горшочек / Potling

| | |
|---|---|
| Id | `sproutsquad:potling` |
| Тип | растение |
| Автор идеи | маскот мода (иконка и логотип) |
| Эскиз | иконка мода `src/main/resources/sprout_squad_icon.png`; текстуры рисует `art/potling/draw_potling.py` |
| Статус | в коде |

**Что умеет:** терракотовый горшок с лицом и ростком. Примерно раз в минуту, если видно солнце, встряхивается и роняет солнце; ночью спит (росток кивает, листья опускаются). Не атакует. Ещё и образец для новых растений: на нём проверен весь путь из `docs/WORKSHOP.md`.

**Характеристики:**

| Параметр | Значение | Ближайший аналог в моде |
|---|---|---|
| Здоровье | 12 | Sunflower — 20, Puff-shroom — 12 |
| Урон | — | — |
| Солнце | примерно раз в 60 с, когда видно солнце | Sunflower — примерно раз в 45 с |
| Стоимость в солнцах | 3 | Sunflower — 5 |

**Как получить:** рецепт без формы — цветочный горшок + семена пшеницы + солнце → пакет семян Горшочка.

**Звуки:** пока звуки оригинала.

**Заметки:** дешевле и слабее подсолнуха — стартовое растение для первого вечера.
