# Тростник-молния

**Растение · разрядник** · Plants & Zombies (оригинал)

Тонкий тростник, который появляется в грозу и бьёт ближних врагов электрическими дугами, перескакивающими на их соседей.

| | |
|---|---|
| Id | `sproutsquad:lightning_reed` |
| Здоровье | 18 |

| Размер | 0,4 × 1,0 блока |

| Как получить | растёт сам только в грозу — на болотах, в мангровых болотах и по берегам рек (группами по 2–3) |

## Умения

- Бьёт цель дугой напрямую: снаряда нет, поэтому разряд не заслонить и от него не увернуться.
- «Электризация II»: каждый электрический удар по цели, начиная с самого разряда, перескакивает на случайное существо той же стороны в пределах 3 блоков с половиной урона и даёт ему ослабленную «Электризацию» — заряд пробегает по толпе. Наэлектризованные существа в воде получают дополнительный урон.
- Невосприимчив к электрическому урону, в том числе к молнии.
- Атакует любых зомби. Приручённый — и других монстров, но никогда криперов; дикий бьёт ещё и игроков.

## Взаимодействия

- Других источников, кроме диких тростников, нет. Приручите тростник солнцем (примерно 19% на каждое солнце), затем выкопайте лопатой, чтобы получить пакет семян, или выращивайте его семена на грядке.
- Хорош в паре с [Электрическим Горохострелом](electric_peashooter.md): его электрические горошины продолжают разносить заряд с существ, наэлектризованных тростником.
- [Электро-Слайд](electric_slide.md) невосприимчив к его электричеству.
