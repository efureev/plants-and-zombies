# Могилоед

<p align="center"><img src="../../images/characters/grave_buster.png" alt="Могилоед" width="320"></p>

**Растение · уничтожает могилы** · Plants & Zombies (оригинал)

Поедает могилы: посаженный на могилу, сгрызает её, роняет её сокровища и исчезает.

| | |
|---|---|
| Id | `sproutsquad:grave_buster` |
| Здоровье | 6 |
| Цена в солнцах | 3 |
| Размер | 1,0 × 1,0 блока |
| Действие | за ~3 с разрушает могилу под собой и роняет добычу (одноразовый) |
| Атака | нет |
| Ночью | не спит |
| Лимит | нет (у большинства растений — 30 в радиусе 32 блоков) |
| Как получить | награды за рейд в почтовом ящике (волны «Зомбиуин!»; обычные волны с 9-й награды); сундуки в мавзолее на Кладбище; выпадает из [Могильщика](grave_digger.md) (10%) и [Зомбимыши](zombat.md) (3%), если их убил игрок или растение; дикий растёт на Кладбище, в Бледном саду, Тёмном лесу и Тёмных подземельях (группами по 1–3); дикого приручают солнцем (~55% за одно солнце) |

## Умения

- Используйте пачку семян на могиле: Могилоед сядет сверху, повернувшись так же, как она.
- Примерно через 3 с жевания он ломает могилу (сам блок не выпадает), роняет добычу из `sproutsquad:chests/gravestone_treasure` и исчезает.
- Могилы ест только приручённый Могилоед (посаженный игроком); дикий просто сидит.
- Зомби не выбирают его целью.
- Выживает не только на почве, но и на могилах.

## Взаимодействия

- Могилы раз за разом призывают зомби, пока в радиусе 24 блоков есть игрок (настройка сервера `graveStoneActivationRange`): в темноте, а в мрачных биомах — в любое время. Могилоед убирает могилу насовсем.
- За первую съеденную могилу дают достижение «Могилоед».
