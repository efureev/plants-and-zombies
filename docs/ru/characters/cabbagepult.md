# Капустопульта

**Растение · катапульта** · Plants & Zombies (оригинал)

Катапульта, которая перебрасывает кочаны капусты через стены и заборы, — врага ей даже не нужно видеть.

| | |
|---|---|
| Id | `sproutsquad:cabbagepult` |
| Здоровье | 20 |
| Цена в солнцах | 5 |
| Размер | 0,9 × 0,8 блока |
| Атака | кочан примерно раз в 2 с, 2 урона, небольшой удар по площади |
| Дальность | 22 блока, прямая видимость не нужна |
| Ночью | не спит |
| Лимит | 30 в радиусе 32 блоков |
| Как получить | растёт сама на равнинах, подсолнечниковых равнинах, в цветочных лесах и лесах (по одной); сундуки в домах деревень |

## Умения

- Бросает по высокой дуге, поэтому достаёт врагов за стенами и заборами, которые остановили бы прямой выстрел. Целится с упреждением.
- При падении кочан ещё и отталкивает существ рядом с местом попадания и немного их ранит; растения не задевает.
- Атакует любых зомби, а приручённая — и других монстров, но никогда криперов. Отвечает тому, кто её ранил.

## Взаимодействия

- Другие катапульты: [Зернопульта](kernelpult.md) (её масло приклеивает цель к месту) и [Арбузопульта](melonpult.md) (сильный урон по площади).
- Дикая приручается солнцем: примерно 36% на каждое солнце.
