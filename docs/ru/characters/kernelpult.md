# Зернопульта

**Растение · катапульта** · Plants & Zombies (оригинал)

Катапульта, которая бросает кукурузные зёрна, а время от времени — кусок масла, приклеивающий цель к месту.

| | |
|---|---|
| Id | `sproutsquad:kernelpult` |
| Здоровье | 20 |
| Цена в солнцах | 6 |
| Размер | 0,9 × 0,8 блока |
| Атака | зерно примерно раз в 1,9 с, 1,5 урона; примерно каждый четвёртый бросок — масло: 3,5 урона + «В масле» на 5 с |
| Дальность | 26 блоков, прямая видимость не нужна |
| Ночью | не спит |
| Лимит | 30 в радиусе 32 блоков |
| Как получить | растёт сама на равнинах, подсолнечниковых равнинах и в саваннах (по одной); сундуки в домах деревень |

## Умения

- «В масле»: цель 5 с не может двигаться, прыгать и атаковать.
- Масло ещё и отталкивает существ рядом с местом попадания и немного их ранит; растения не задевает. Зёрна отбрасывают цель.
- После каждого броска с шансом 25% следующий будет маслом; тогда масло видно на растении ещё до выстрела.
- Бросает по высокой дуге, поэтому достаёт врагов за стенами и заборами, которые остановили бы прямой выстрел. Целится с упреждением.
- Атакует любых зомби, а приручённая — и других монстров, но никогда криперов. Отвечает тому, кто её ранил.

## Взаимодействия

- Масло задерживает зомби на месте для [Арбузопульты](melonpult.md), [Чомпера](chomper.md) или [Вишнёвой Бомбы](cherrybomb.md).
- Дикая приручается солнцем: примерно 30% на каждое солнце.
