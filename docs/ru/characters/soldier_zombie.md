# Зомби-Солдат

**Зомби · стрелок** · Plants & Zombies (оригинал)

Бронированный стрелок с Пейнтбольным маркером. Держится на расстоянии и осыпает цель шариками с краской.

| | |
|---|---|
| Id | `sproutsquad:soldier_zombie` |
| Здоровье | 35 |
| Броня | 6 |
| Урон | шарик с краской 1; ближнего боя нет |
| Скорость | 0,237 |
| Сопротивление отбрасыванию | 0,2 |
| Размер | 0,6 × 1,95 блока |
| Появление | сам в мире не появляется |
| Рейды | обычные волны с 11-й и «Робо-Армия» (волны 10–16) — и там и там только после того, как начавший рейд игрок посмотрел финальные титры; в «Робо-Армии» на каждом третьем [Робо-Зомби](robo_zombie.md) сидит Солдат |
| Лидер / босс | может быть лидером (`can_be_leader`), но, раз сам в мире не появляется, группу никогда не зовёт; боссом не бывает |
| Добыча | 2 %: Пейнтбольный маркер с прочностью 60–90 %, если убил игрок или растение |

## Умения

- Примерно раз в 2 с стреляет шариком с краской по целям на расстоянии до 50 блоков.
- Держится примерно в 7 блоках от цели и всегда смотрит на неё.
- Каждое попадание красит цель в цвет солдата (эффект «Покрашен», 11 с, усиливается с новыми попаданиями; только внешний вид, смывается в воде).
- Цвет случайный: зелёный, фиолетовый, оранжевый или синий.
- Ломает двери.
- Обладает [общими чертами зомби мода](browncoat.md#общие-черты-зомби-мода).

## Взаимодействия

- В волне «Робо-Армия» может ехать верхом на [Робо-Зомби](robo_zombie.md); такой Робо-Зомби сразу появляется в облике танка.
- Выпавший с него Пейнтбольный маркер позволяет и игроку стрелять шариками с краской.
