# Горшочек

<p align="center"><img src="../../images/characters/potling.png" alt="Горшочек" width="320"></p>

**Растение · даёт солнце** · Sprout Squad

Маскот мода: терракотовый горшок с лицом и ростком из двух листьев. Дешёвое стартовое растение, которое понемногу даёт солнце, и образец, по которому строятся все новые растения Sprout Squad.

| | |
|---|---|
| Id | `sproutsquad:potling` |
| Здоровье | 12 |
| Цена в солнцах | 3 |
| Размер | 0,65 × 1,0 блока |
| Солнце | 1 солнце примерно раз в 60 с, пока видно солнце |
| Ночью | спит |
| Как получить | рецепт без формы: цветочный горшок + семена пшеницы + 3 солнца → пакет семян Горшочка |

## Умения

- Примерно раз в минуту, если видит солнце, встряхивается и роняет солнце.
- Не атакует.
- Ночью спит: росток кивает вперёд, листья опускаются.

## Заметки

- Вместе с 3 солнцами за посадку выходит чуть дороже [Подсолнуха](sunflower.md), который даёт солнце быстрее (примерно раз в 45 с): рецепт не превращается в бесконечную ферму солнца.
- Пока со звуками оригинального мода.
