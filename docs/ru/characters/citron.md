# Цитрон

**Растение · ходячий лазер** · Plants & Zombies (оригинал), экспериментальное

Ходячий цитрус, который гонится за врагами и стреляет в них тонким лазерным лучом. Экспериментальный: скрыт, пока не включены экспериментальные возможности.

| | |
|---|---|
| Id | `sproutsquad:citron` |
| Здоровье | 50 |
| Цена в солнцах | нет (не входит в список цен, сажается бесплатно) |
| Размер | 0,85 × 0,76 блока |
| Скорость | 0,22 (у ванильного зомби — 0,23) |
| Сопротивление отбрасыванию | 0,1 |
| Атака | лазер примерно раз в 1,65 с, 3 урона всем на линии |
| Дальность | 32 блока |
| Ночью | не спит |
| Как получить | только из творческой вкладки, если в `config/sproutsquad/server.json` выставить `enableExperimentalFeatures` в `true`; в добыче и дикой природе не встречается |

## Умения

- Идёт к цели и стреляет на ходу.
- Луч шириной 1,5 блока проходит сквозь всех врагов на линии; урон — энергетический, цель должна быть в прямой видимости.
- Если игрок ударит приручённый Цитрон Садоводской перчаткой, тот покатится, как [Стенорех](wallnut.md), и будет скакать, пока не сбавит ход; каждый удар изнашивает перчатку.
- Атакует зомби (и мода, и ванильных); приручённый — ещё и враждебных мобов; дикий — и игроков.

## Взаимодействия

- Толчок садовой перчаткой заставляет его катиться и на 15 с превращает в шар: быстрее, шагает на целый блок и держится в 8 блоках от цели (включено в Sprout Squad; в оригинале переход не срабатывал).
- Не нужен для достижения «Ботаник» (посадить по одному растению каждого вида).
- Второе экспериментальное ходячее растение — [Королевский Подсолнух](royal_sunflower.md).
