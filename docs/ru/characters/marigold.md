# Бархатцы

<p align="center"><img src="../../images/characters/marigold.png" alt="Бархатцы" width="320"></p>

**Растение · даёт сокровища** · Plants & Zombies (оригинал)

Растение для фермы: вместо пакета семян с них собирают золотые слитки, изумруды и алмазы.

| | |
|---|---|
| Id | `sproutsquad:marigold` |
| Здоровье | 16 |
| Цена в солнцах | 5 |
| Размер | 0,6 × 0,94 блока |
| Атака | нет |
| Ночью | не спят |
| Лимит | 30 в радиусе 32 блоков |
| Как получить | награды за рейд в почтовом ящике (сложные волны); в дикой природе не растут |

## Умения

- Не атакуют, не дают солнца и не отвечают на удары.
- Вся ценность — в урожае. Как и другие растения, прирученные бархатцы на грядке или в горшке дзен выращивают семена: их нужно полить, дать отдохнуть, а затем кормить солнцем по одному.
- На один урожай нужно около 32 солнц — гораздо больше, чем другим растениям. Урожай — 4–6 выпадений золотых слитков, изумрудов или алмазов (алмазы реже всего), и с шансом 1% — Золотой садовый гном.
- Пока их кормят, вокруг разгораются искры: чем больше получено солнца, тем их больше.

## Взаимодействия

- Правый клик красителем по своим (ручным) бархатцам перекрашивает цветы (16 цветов; с `coopPlanting` — по ручным бархатцам любого игрока). Бирка с именем «Rainbow» делает их радужными, «Flowey» — даёт другой особый вид. Добавлено в Sprout Squad: текстуры были в оригинале, но не использовались.
- Большой запас воды (ведро, лейка) вдвое уменьшает число солнц, нужное другим растениям для семян, но не бархатцам: их 32 солнца не меняются.
- Солнце дают [Подсолнухи](sunflower.md) и другие растения-производители.
- Если назвать их биркой `flowey`, они сменят облик.
