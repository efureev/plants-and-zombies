# Кофейный Боб

**Растение · поддержка** · Plants & Zombies (оригинал)

Одноразовый будильник: будит спящее растение рядом с собой на 40 минут и исчезает.

| | |
|---|---|
| Id | `sproutsquad:coffeebean` |
| Здоровье | 4 |
| Цена в солнцах | 2 |
| Размер | 0,4 × 0,5 блока |
| Действие | будит ближайшее спящее растение в пределах ~1 блока; оно не спит 40 мин |
| Атака | нет |
| Ночью | не спит |
| Лимит | нет (у большинства растений — 30 в радиусе 32 блоков) |
| Как получить | награды за рейд в почтовом ящике за волны «Зимняя Страна Чудес!»; дикий растёт в джунглях группами по 2–5; дикого приручают солнцем (~67% за одно солнце) |

## Умения

- Посадите его вплотную к спящему растению — обычно это гриб днём. Примерно через 1,5 с Боб будит его и исчезает.
- Быстрее: используйте пачку семян Кофейного Боба прямо на спящем растении. Оно проснётся сразу за те же 2 солнца, а сажать ничего не придётся.
- Бодрость длится 48 000 тиков (40 мин; настройка сервера `coffeeBuffDuration`), её видно по частицам энергии.
- Растение, которое выращивает семена на пашне, разбудить нельзя.
- Выживает на любом твёрдом блоке, не только на почве.
- Не атакует и не даёт сдачи.

## Взаимодействия

- Пригодится всем грибам: [Пуффгрибу](puffshroom.md), [Трусогрибу](scaredyshroom.md), [Дымогрибу](fumeshroom.md), [Солнцегрибу](sunshroom.md), [Гипногрибу](hypnoshroom.md), [Ледогрибу](iceshroom.md), [Грибу Судьбы](doomshroom.md) и [Морегрибу](seashroom.md).
