# Кактус

<p align="center"><img src="../../images/characters/cactus.png" alt="Кактус" width="320"></p>

**Растение · дальнобойный стрелок** · Plants & Zombies (оригинал)

Пустынный снайпер: стреляет пробивающими иглами по самому дальнему врагу, которого видит, и лопает воздушные шарики.

| | |
|---|---|
| Id | `sproutsquad:cactus` |
| Здоровье | 20 |
| Цена в солнцах | 6 |
| Размер | 0,8 × 1,25 блока |
| Атака | игла примерно раз в 2,3 с, 1,5 урона, пробивает несколько целей |
| Дальность | 34 блока, нужна прямая видимость |
| Ночью | не спит |
| Лимит | 30 в радиусе 32 блоков |
| Как получить | растёт сам в пустынях и пустошах (группами по 1–3) |

## Умения

- Выбирает самую дальнюю цель в радиусе, а не ближайшую.
- Если к цели привязаны воздушные шарики, сначала стреляет в шарик и лопает его.
- Иглы летят быстро и прошивают несколько существ подряд. Игла, застрявшая в земле, исчезает через 5 с.
- Стреляет по любым зомби, а приручённый — и по другим монстрам, но никогда по криперам. Целится с упреждением и отстреливается от того, кто его ранил.
- Кроме почвы, сажается на песок, красный песок, песок душ и прямо на блок кактуса.

## Взаимодействия

- Как и все растения, не получает урона от блоков кактуса.
- Дикий приручается солнцем: примерно 30% на каждое солнце.
