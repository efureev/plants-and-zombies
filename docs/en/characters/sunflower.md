# Sunflower

<p align="center"><img src="../../images/characters/sunflower.png" alt="Sunflower" width="320"></p>

**Plant · sun producer** · Plants & Zombies (original)

The basic economy plant: it does not fight, but regularly drops sun that pays for planting everything else.

| | |
|---|---|
| Id | `sproutsquad:sunflower` |
| Health | 20 |

| Size | 0.6 × 1.1 blocks |
| Sun | 1 sun about every 45 s while awake |
| Attack | none |
| At night | sleeps |
| Limit | 30 within 32 blocks |
| How to get | grows wild in plains, sunflower plains and flower forests (groups of up to 4); rare drop (1%, shared with Peashooter and Wall Nut) from a [Browncoat](browncoat.md) killed by a player or a plant |

## Abilities

- About every 45 s it drops one sun. It starts to glow shortly before the sun appears.
- Sleeps whenever it cannot see the sun — at night and underground. While it sleeps the timer stops and no sun is made.
- Does not attack and does not fight back.

## Interactions

- A wild Sunflower is tamed by feeding it sun: about 36% chance per sun.
- A [Coffee Bean](coffeebean.md) wakes it up. A Sunflower can make sun in the dark, so an awake one keeps producing through the night.
- Named `vampire` with a name tag, it gets a different look.
- A [Potling](potling.md) can be crafted, but makes sun more slowly (about every 60 s).
