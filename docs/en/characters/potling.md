# Potling

<p align="center"><img src="../../images/characters/potling.png" alt="Potling" width="320"></p>

**Plant · sun producer** · Sprout Squad

The mod's mascot: a terracotta pot with a face and a two-leaf sprout. A cheap starter plant that slowly makes sun, and the template every new Sprout Squad plant is built from.

| | |
|---|---|
| Id | `sproutsquad:potling` |
| Health | 12 |
| Sun cost | 3 |
| Size | 0.65 × 1.0 blocks |
| Sun | 1 sun about every 60 s while the sun is visible |
| At night | sleeps |
| How to get | shapeless recipe: flower pot + wheat seeds + 3 sun → Potling seed packet |

## Abilities

- About once a minute, if it can see the sun, it shakes and drops a sun.
- Does not attack.
- Sleeps at night: the sprout nods forward and the leaves droop.

## Notes

- With the 3 sun spent on planting it costs a little more than a [Sunflower](sunflower.md), which produces faster (about every 45 s): the recipe is not an endless sun farm.
- Uses the original mod's sounds for now.
