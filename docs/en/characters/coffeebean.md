# Coffee Bean

**Plant · support** · Plants & Zombies (original)

A one-shot wake-up call: it wakes a sleeping plant next to it for 40 minutes and then disappears.

| | |
|---|---|
| Id | `sproutsquad:coffeebean` |
| Health | 4 |
| Sun cost | 2 |
| Size | 0.4 × 0.5 blocks |
| Effect | wakes the nearest sleeping plant within ~1 block; it stays awake for 40 min |
| Attack | none |
| At night | stays awake |
| Limit | none (most plants: 30 within 32 blocks) |
| How to get | raid rewards in the Mailbox for "Winter Wonderland!" waves; grows wild in jungles, in groups of 2–5; a wild one is tamed with sun (~67% per sun) |

## Abilities

- Plant it right next to a sleeping plant, usually a mushroom in daylight. About 1.5 s later it wakes that plant and vanishes.
- Quicker way: use the Coffee Bean seed packet directly on a sleeping plant. It wakes at once for the same 2 sun, and nothing is planted.
- The wake-up lasts 48,000 ticks (40 min; server setting `coffeeBuffDuration`); energized particles show it.
- A plant that is growing seeds on farmland cannot be woken.
- Survives on any solid block, not only on soil.
- Does not attack and does not fight back.

## Interactions

- Useful for every mushroom: [Puff Shroom](puffshroom.md), [Scaredy Shroom](scaredyshroom.md), [Fume Shroom](fumeshroom.md), [Sun Shroom](sunshroom.md), [Hypno Shroom](hypnoshroom.md), [Ice Shroom](iceshroom.md), [Doom Shroom](doomshroom.md) and [Sea Shroom](seashroom.md).
